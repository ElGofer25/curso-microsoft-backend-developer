# Microsoft Course: Become a backend developer

Apuntes y práctica del curso **Foundations of Coding: Back-End**, primer curso del
programa [Microsoft Back-End Developer](https://www.coursera.org/professional-certificates/microsoft-back-end-developer)
de Coursera. Este repositorio documenta lo que voy aprendiendo: cada módulo
tiene apuntes propios, escritos en español con mis palabras.

## Sobre el curso

Introduce los principios del desarrollo back-end (la parte de una aplicación que
corre en el servidor: lógica de negocio, datos y APIs) y el rol de un ingeniero
back-end. Está organizado en 6 módulos y utiliza **C#** sobre el ecosistema **.NET**.

## Herramientas y tecnologías

| Herramienta | Para qué sirve |
|---|---|
| **C# / .NET** | Lenguaje fuertemente tipado y orientado a objetos, y la plataforma multiplataforma (Windows, macOS, Linux) en la que se ejecuta. |
| **Git** | Sistema de control de versiones: registra cada cambio del código y permite volver atrás. |
| **GitHub** | Plataforma para alojar repositorios Git y colaborar mediante `issues` y `pull requests`. |
| **IDE / editor de código** | Entorno donde se escribe, ejecuta y depura el código. |
| **Microsoft Copilot** | Asistente de IA de apoyo al desarrollo. |
